
# Student Grade Calculator

A beginner-friendly C program that calculates the total marks, percentage, and grade of a student based on marks entered for five subjects.

## Features
- Accepts marks for five subjects.
- Calculates total marks.
- Calculates percentage.
- Displays the grade based on percentage.

## Technologies Used
- C Programming
- Standard Input/Output

## How to Run

1. Download the `student_grade_calculator.c` file.
2. Open it in a C compiler.
3. Compile and run the program.
4. Enter marks for five subjects.

## Grading System

| Percentage | Grade |
|---|---|
| 90 and above | A |
| 75–89 | B |
| 60–74 | C |
| 40–59 | D |
| Below 40 | Fail |

- Arrays
